📜 Integrated Slash Commands
Command Description Access
/card set-template Upload or update this server's official template (attachment or URL). Auto-normalized to 1200×900 PNG. Administrator / Staff
/card view-template Inspect active card template, resolution, and stamping blueprint for this server. Everyone
/card reset-template Removes custom template and reverts to the official standard UOI template. Administrator / Staff
/card setup Configures staff review channel, delivery channel, and reviewer role. Unlocks server commands. Administrator
/card generate Submits a citizen ID application to the staff review channel. Citizens (Requires Setup)
/card show [target] Retrieves and displays a registered citizen card from the central database. Everyone
/card whois [citizen] Auto-detects linked Roblox account, 3D avatar headshot, numerical ID, and verification dossier. Everyone
/card verify [serial] Validates card authenticity and status (VALID / REVOKED). Everyone
/card inspect [query] Displays comprehensive audit trails and issuer details. Staff Officers
/card promote Promotes citizen to a higher hierarchy rank and updates card. Staff Officers
/card revoke Disciplinary card cancellation with required audit reason. Staff Officers
/card botstyle Applies Discord name styles with Font 10 (Sinistre Vampyre), Neon Glow, and custom colors. Administrator
/card memory Inspects permanent server memory, channel routing, and persistent database storage status. Everyone
/card git-status Inspects active Git commit SHA, branch, deployment details, and webhook auto-restart pipeline. Everyone
/card git-sync Pulls latest commits from repository and gracefully reboots the server with zero data loss. Administrator

⚡ Staff Review Workflow
1
Citizen Applies: Citizen runs /card generate. The card is not issued immediately.
2
Staff Channel Notification: An embed arrives in the configured staff review channel with citizen avatar, Roblox username, rank, and [Accept] / [Decline] buttons.
3
Staff Decision: Clicking Accept generates the card, saves it to the vault, updates the citizen's nickname, and posts to the delivery channel. Clicking Decline opens a modal requiring a rejection reason and notifies the applicant.
